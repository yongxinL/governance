# Documentation Exceptions

Records temporary and standing exceptions to Nexora Governance for this
project. One-time feature or release deviations normally remain in the affected
artifact rather than here.

Exceptions cannot waive NX-1 through NX-6.

## Active exceptions

No exceptions have been recorded.

## Identifier allocation

`EXC-NNN` is a **project-local** label for this register. It is not a centrally
allocated identifier family; the central governance package does not allocate,
reserve, or audit exception numbers across projects.

Allocate the next unused number in this project only. Identifiers are never
reused, including after an exception is resolved or withdrawn. Retired records
stay listed with their resolution date so history remains auditable.

## Approval placeholders

`Pending` records that approval has **not** occurred. It is never evidence that
it did. Do not pre-populate an approver, an approval mode, an approval date, or
approval evidence: fill these only from a real Project Owner decision.

## Resolved and withdrawn exceptions

Resolved and withdrawn exceptions remain listed with their resolution date and
are never deleted, so identifier history stays intact.
